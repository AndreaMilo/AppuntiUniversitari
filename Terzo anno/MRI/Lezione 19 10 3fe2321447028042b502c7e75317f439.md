# Lezione 19/10

Una parte importante nello studio della rilevanza è il **relevance feedback**, ovvero la possibilità che l’utente segnali come rilevante o meno un set di risultati cosicchè il sistema possa rielaborare una query includendone il feedback.

Il processo di modifica della query è detto:

- relevance feedback quando l’utente da informazioni sulla rilevanza dei documenti
- query expansion quando delle informazioni legate alla query ne espandono il risultato.

Entrambe verranno dette metodi di feeback.

I metodi di feeback possono essere:

- impliciti → le informazioni sono derivate dal sistema
- espliciti → l’utente fornisce direttamente informazioni

- in base al numero di documenti rilevanti si deve cercare di dare un peso maggiore
